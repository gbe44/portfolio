Kanbo is a kanban task manager you can install with a single Docker command. SQLite storage, real-time interface, zero telemetry.

- Real-time sync over WebSocket, offline mode included.
- Installed in under two minutes: one Docker image, one volume.
- On pause, but still used by three teams as far as I know.
